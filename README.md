# 📄 Currículo Online - Projeto de Estudo

 🔗 **Link para o projeto online:** [Acesse aqui o meu currículo](https://BrunnoAra.github.io/curriculo-html)

Este é o meu primeiro projeto prático focado na minha transição de carreira para a área de Tecnologia (TI). Desenvolvi um currículo web responsivo utilizando **HTML5** e **CSS3** totalmente do zero, aplicando conceitos estruturais modernos, semântica web e boas práticas de estilização.

---

## 📸 Demonstração


https://BrunnoAra.github.io/curriculo-html/

---

## 🛠️ Tecnologias e Conceitos Utilizados

* **HTML5**: Estruturação semântica, garantindo acessibilidade e melhor indexação.
* **CSS3**: Estilização moderna, uso de seletores, manipulação de cores, fontes e conceitos de **Responsividade** (adaptação para ecrãs de telemóvel e computador).
* **Git e GitHub**: Controle de versão do código, organização de commits e publicação através do **GitHub Pages**.

---

## 🧠 Aprendizados e Desafios

* **Semântica Web**: Compreensão de como utilizar as tags corretas (`<header>`, `<main>`, `<section>`, `<footer>`) para criar uma estrutura limpa e legível.
* **Estilização e Layout**: Aplicação prática de propriedades CSS para criar uma interface visualmente agradável, organizada e profissional.
* **Workflow de Desenvolvimento**: Domínio do fluxo básico de Git (`git add`, `git commit`, `git push`) para gerir o histórico do projeto.
